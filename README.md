# BoardGameBuddy

BoardGameBuddy is an Android app for managing a personal board game collection.  
The app lets users register, log in, and save board games with useful details such as player count, play time, difficulty, categories, and personal rules notes.

## Features

- User registration and login using Firebase Authentication
- Personal board game collection stored in Firebase Realtime Database
- Add new board games
- Edit existing board games
- Delete board games
- View game details in a clean list
- Save information such as:
  - Minimum and maximum players
  - Best player count
  - Average play time
  - Difficulty level
  - Categories/tags
  - Played status
  - Rules or personal notes
- Firebase offline persistence support

## Technologies Used

- Java
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Android Navigation Component
- RecyclerView
- Material Components
- Gradle Kotlin DSL
